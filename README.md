# Siemens Personal Projects

This repository contains personal projects, examples, notes, and supporting material related to Siemens automation technologies.

## Purpose

The material is made available for study, learning, experimentation, and personal reference. It is intended to help learners explore industrial automation concepts and related engineering practices.

## Contents

Projects may include, where applicable:

- PLC programs and example logic
- HMI configuration examples
- Documentation, notes, and diagrams
- Test data and learning exercises
